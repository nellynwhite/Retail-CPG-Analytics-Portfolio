The decisions that shaped the model, each stated as the choice made, why it was made, and the result it produced.

Design decisions
Composite date keyResolved
Decision
Dim_Date held both TY and LY weeks, so week_id repeated and broke 1:Many. A composite key of week_id and fiscal_year_label was added instead of splitting the dimension.
Why
Keeping one dimension preserves the simple column-subtraction YoY pattern. Splitting into two date tables would have doubled relationships and added model bloat.
Result
All four fact relationships resolve at 1:Many. Filter propagation confirmed across all 77 measures.
TY/LY as columnsIntentional
Decision
Store TY and LY as columns in the same fact row rather than relying on Power BI time intelligence.
Why
Walmart's NRF calendar starts Q1 in February, so DATEADD and SAMEPERIODLASTYEAR misalign YoY by one to two weeks. The column pattern also mirrors how Scintilla exports data.
Result
No time intelligence functions used. YoY is exact and matches the source system structure.
Import over DirectQueryTrade-off
Decision
Use Import mode at this data volume, with SQL views structured to support a later DirectQuery move.
Why
At 52K fact rows the model compresses under 10MB and renders in under one second, versus 2 to 4 seconds in DirectQuery testing. Production volume would change this call.
Result
Sub-second renders across all pages; a clear migration path retained.
Explicit boolean filtersResolved
Decision
Every CALCULATE filter on a boolean column uses an explicit = TRUE() comparison.
Why
A bare boolean reference is read as a table filter and can apply inconsistently, returning a number that is silently wrong.
Result
All 14 boolean filtered measures return correct values across every slicer combination.

Judgment that mattered most
The headline OTIF figure (the soft 91.3% average) looked acceptable. Separating on time from in full changed the story: the real compliance rate is 55.0% and the failure is short shipments, not late ones. That distinction redirects the fix from carriers to order accuracy, and is the finding the rest of the portfolio is built around.
