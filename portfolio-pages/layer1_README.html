Portfolio design philosophy

Every project in this portfolio mirrors a real vendor analytics workflow — the kind that runs between a CPG supplier and a major retailer. Each is built end-to-end: data model to SQL views to Power BI dashboard to executive output. The synthetic dataset is modeled on Walmart Scintilla's vendor portal structure, with enforced data quality, realistic YoY growth patterns (~6.3–6.8%), and accurate promo lift mechanics across four trade mechanic types. Documentation — READMEs, data dictionaries, DAX reference guides — is treated as a deliverable on the same level as the dashboards themselves.
